# Prelim Activity 01: Codac Logistics Delivery & Fuel Auditor

Name: Villalino, Clarens Lerwin S.
Course & Section: BSIT 3.2

## Description
This project is a C# console application developed for Codac Logistics.
It collects driver information, validates distance input, tracks fuel
expenses for five days, analyzes fuel efficiency, and generates
an audit report.

## Features
- Driver profile input
- Distance validation using while loop
- Fuel expense tracking using arrays
- Performance analysis with if-else
- Formatted audit report

## Technologies Used
- C#
- .NET Console Application
- Visual Studio Code

## How to Run
1. Open the project folder
2. Open terminal
3. Run the command:

   dotnet run
